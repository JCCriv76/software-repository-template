# Architectural decision records

ADRs preserve decisions whose reasoning would otherwise disappear into chat, issue comments, or
model transcripts.

## Status values

- `proposed` — under review, not authoritative;
- `accepted` — current decision;
- `deprecated` — still present but scheduled for removal;
- `superseded by ADR-NNNN` — replaced by a newer decision;
- `rejected` — considered and deliberately not chosen.
